# UnitySceneMerger

Семантическое трёхстороннее слияние файлов сцен Unity для Git: сцена сливается как граф объектов, а не построчно.

Стек: C#, .NET 9, YamlDotNet, xUnit.

## Процесс
- Задачи — Jira-проект `USM`, ключ задачи пишется в названии ветки и Pull Request (`USM-1 ...`).
- Ветка `main` защищена, изменения — только через Pull Request.
- Документация — Confluence-пространство `UnitySceneMerger_Тонкин_МПР21`.
